# 《星黎同行：逆时弹头》Run-Gun Demo 规则文档

日期：2026-04-30  
版本：production runtime v1

## 项目定位

《星黎同行：逆时弹头》是复古像素横版跑枪 Demo。玩家选择一名未排期者，在星黎伴飞支援下连续突破三条封锁线，并在通关后进入更高难度或无尽地狱刷分。

核心参考方向：

- 《魂斗罗》的横版跑枪、跳跃躲弹和 Boss 几何弹幕。
- 《合金弹头》的推进节奏、敌群压迫、道具升级和爆炸反馈。
- 星黎 OS 的陪伴感：星黎不是普通挂件，而是同步火力、护盾和清屏大招核心。

## 当前角色

### 断刃者

- 定位：均衡突击型。
- 火力：中距离步枪，升级后子弹变宽、带波动轨迹和更高覆盖。
- 适合：标准跑枪节奏、稳定推进。

### 弧焰技师

- 定位：中近距离范围压制。
- 火力：火枪 / 弧焰喷射，升级后喷射距离和扇面增强，但不会变成长距离狙击。
- 特点：对盾兵和地面密集敌人更强。

### 霁线游侠

- 定位：高伤穿透射线。
- 火力：磁轨 / 激光类攻击，低射速高伤害，满级后激光束更长、更明显。
- 特点：适合处理直线敌群和 Boss 弱点。

## 星黎同步系统

星黎通过粉蓝能量道具激活与升级。

- 同步等级最高 LV.5。
- 能量槽满 3 格后继续吃星黎能量会提升同步等级。
- 普通、困难、地狱的连续三关之间不继承星黎等级。
- 无尽地狱 route 之间继承星黎等级、武器等级、分数和剩余血量。

星黎基础攻击形态：

| 等级 | 自动攻击表现 |
| --- | --- |
| LV.1 | 星辉单发 |
| LV.2 | 双星辉弹 |
| LV.3 | 星辉碎片弹 |
| LV.4 | 双星轨长枪束 |
| LV.5 | 星形侧弹 + 中央星轨长枪束 |

大招规则：

- `K / ULT` 释放星黎大招。
- 0 格也可应急释放小范围星爆。
- 1-2 格为范围爆发。
- 3 格触发星黎过场和清屏级大招。
- Boss 不会被秒杀，但会被削血、打断弹幕并清除屏幕威胁。

## 道具系统

| 道具 | 作用 |
| --- | --- |
| P | Power，提升伤害、破盾值或主弹威力 |
| W | Wide，提升宽度、扇面、波动或穿透判定 |
| R | Rapid，提升射速、节奏和部分武器表现 |
| 星黎能量 | 提升星黎能量槽 / 同步等级 |
| HP | 恢复生命 |

每种武器升级最高 3 级。普通战役跨关会重置武器等级；无尽地狱 route 间保留。

## 三关结构

玩家先选择任意关卡作为起点，通关后会按循环顺序继续剩余两关。

| 关卡 | 名称 | 主题 | Boss |
| --- | --- | --- | --- |
| 01 | 夜城天台 | 雨夜赛博屋顶、跳台、基础跑枪 | 零点巡逻艇 |
| 02 | 霓虹贫民窟 | 雨巷、地面压迫、重型机械 | 雨巷回收机 |
| 03 | 虚拟深层 | 数码虚域、数据弹幕、闪现敌人 | 镜像守门者 |

失败重试规则：

- 普通、困难、地狱中任意关卡死亡，按 `R / RETRY` 重试当前失败关卡。
- 不会跳回当前模式第一关。
- 无尽地狱死亡后不能 retry，只能返回主界面重新开始。

## Boss 设计

### Boss 1：零点巡逻艇

- 主轴：导弹攻击。
- 普通攻击：扇形导弹、密集弹幕、阶段后加入下坠导弹。
- 玩家目标：在密集弹幕中寻找跳跃和蹲伏空间。

### Boss 2：雨巷回收机

- 主轴：地面技能型 Boss。
- 普通攻击：地面冲击波、多层地面压制、抛物线榴弹。
- 场地：地面 Boss 战场，不悬浮。
- 玩家目标：处理地面技能，同时利用台阶躲避重型冲击。

### Boss 3：镜像守门者

- 主轴：虚拟幽灵、闪现、全屏竖线技能。
- 普通攻击：旋转几何弹幕、数据球、竖线柱预警。
- 玩家目标：读 Boss 闪现位置和全屏线条节奏。

## 难度与通关流转

### 普通模式

- 三关全通后，提示按 `R` 进入困难模式，或按 `MENU` 返回主页。

### 困难模式

- Boss 血量是基础倍率 `2.0`。
- 左侧高速突击敌人出现率约为普通的 2 倍。
- 三关全通后，提示按 `R` 进入地狱模式，或按 `MENU` 返回主页。

### 地狱模式

- Boss 血量是困难模式的 1.5 倍，倍率 `3.0`。
- 每一关 Boss 需要打两遍。
- 左侧高速突击敌人出现率约为普通的 3 倍。
- 三关全通后，提示按 `R` 进入无尽地狱模式，或按 `MENU` 返回主页。

### 无尽地狱模式

- 从地狱三关全通后进入。
- 每个 route 随机关卡地图、敌人资产、Boss 资产。
- 每通过一个 route，难度增加 20%。
- route 之间继承分数、武器等级、星黎等级和剩余血量。
- 直到玩家死亡结束。
- 死亡后按 `R / MENU` 返回主界面，不能直接 retry。

## 敌人刷新规则

- 普通敌人主要从右侧推进。
- 关卡中段会出现左侧高速突击敌人。
- 左侧突击敌人不会在 Boss 前后刷出。
- 普通模式左侧突击占比约 20%。
- 困难模式约 40%，场上最多 4 个。
- 地狱模式约 60%，场上最多 6 个。
- 无尽地狱会随 route 增长继续提高压力。

## 排行榜规则

排行榜存储在本机浏览器 localStorage。

显示顺序：

1. 无尽地狱最高到达 route，未开启显示“未开启”。
2. 玩家最高积分和对应模式类型。
3. 最近游玩的轮数积分记录。

无尽地狱死亡时记录最终分数和 route；普通 / 困难 / 地狱三关通关或失败时记录对应成绩。
